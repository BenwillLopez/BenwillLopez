# Excel practice: Platzi *Excel – Aplicación Práctica*

Exercises from Platzi's practical Excel course. Each workbook uses the same practice dataset of
fictional visitors and investors, with fields for name, investment amount, length of stay, sector,
intent (invest or work), investment detail, whether they know a project, and country of origin.

| Workbook | Sheets | Records | Topic |
|---|---|---:|---|
| [`reto-tabla-y-formatos.xlsx`](reto-tabla-y-formatos.xlsx) | Reto 1, Reto 2 | 100 each | Challenge: turning raw data into formatted tables |
| [`bases-de-datos-clase-9.xlsx`](bases-de-datos-clase-9.xlsx) | Clase 9 | 320 | Class 9: working with data as a database (codes, sorting, filtering) |

The workbooks are in Spanish, as in the course. All names and amounts are practice data, not real
people.
