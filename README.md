### hey, i'm benwill

been sideloading for a while. i kept adding source after source only to find the same app at
three different versions, half the downloads dead, and nothing that kept itself up to date.
i looked for one feed that had everything and stayed current. couldn't find it, so i built it.

### accretion

<a href="https://getaccretion.github.io/">
<picture>

160+ public AltStore and SideStore repos merged into one feed. one entry per app, and the newest
build wins. it rebuilds every 6 hours, finds new repos by itself every week, checks every
download link daily, and anything that doesn't meet the AltStore spec doesn't ship. the numbers
above redraw on every build.

browse it in your browser: **[getaccretion.github.io](https://getaccretion.github.io/)**
search every app, filter by category, and open any app's page for versions, what's new and
download or install buttons.

or add the source:

```
https://getaccretion.github.io/source.json
```

lighter, hand-picked repos only:

```
https://getaccretion.github.io/curated.json
```

works in the iOSGods App, AltStore, SideStore, Feather and ESign.
