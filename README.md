## 🚀 Featured project: [Accretion](https://github.com/BenwillLopez/accretion)

<a href="https://github.com/BenwillLopez/accretion"><img src="https://raw.githubusercontent.com/benwilllopez/accretion/main/assets/header.png" alt="Accretion: every source, pulled into one" width="100%"></a>

In space, *accretion* is how gravity pulls scattered matter into one body. **Accretion** does the
same for iOS apps. It is an app source in the AltStore JSON format that merges 160+ public
AltStore and SideStore sources into one link and keeps only the **newest version** of every app.

- 🪐 Rebuilt every 6 hours. New sources are discovered automatically every week.
- ✅ Every app is checked against the AltStore format, links are https only, and dead downloads are removed daily.
- 📱 Works in the iOSGods App, AltStore, SideStore, Feather and ESign.
